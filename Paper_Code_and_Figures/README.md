# Paper code and figures

Notebooks that reproduce the figures and supplementary tables of *"Analytical validation pipeline
for generating highly specific functional gene expression signatures"*. Notebooks are thin: they
load data, set parameters, call `signature_validation` (install it first, see the
[root README](../README.md)) and save plots / tables.

## Running a notebook

1. Install the library into a virtual environment (`pip install -e .` from the repository root).
2. Open the notebook and fill in the data-locations cell: every `<PATH_TO_...>` placeholder must
   point to your local copy of the data. The input data are not public (see *Data availability* in
   the root README).
3. Run the notebook from its own folder — relative output paths (`./plots/`, `./figures/`,
   `../plots/...`) are resolved from there.

Generated plots, tables and cached pickles are git-ignored and regenerated by the notebooks; the
SVGs committed under `plots/` are the versions used in the paper.

## Terminology

- **FGES** — functional gene expression signature; **GOI** — group of interest (the cell type or
  condition an FGES should score high in); **controls** — samples in which the FGES is expected
  to score low.
- **Main4_\*** — internal (pipeline-derived) FGES names used in code, e.g.
  `Main4_Pan_macrophage_signature`.
